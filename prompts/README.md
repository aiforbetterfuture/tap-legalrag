# 프롬프트 저장소

시스템이 사용하는 모든 프롬프트를 코드에서 분리해 여기에 둔다.

## 왜 분리하나
- 프롬프트는 가장 자주 수정되는 부분. 코드에 묻히면 수정마다 코드를 건드려야 한다.
- 파일로 두면 버전 관리가 되고, 논문 부록에 그대로 실을 수 있다.
- 코드 수정 없이 프롬프트만 교체·실험할 수 있다.

## 파일
- `system_policy.txt` — 답변 생성 시 항상 부과하는 시스템 정책
- `clarification.txt` — (V3) 명확화 질문 생성 지시

## 사용
`law_rag.prompts.load(name)` 으로 읽는다. 파일명(확장자 제외)이 name.
