# DATASETS — 데이터셋 지도

숫자가 여러 개(100·97·91·86·60···) 나오는 이유를 한눈에. 각 실험이 **어떤 집합**을 **몇 건** 쓰는지 고정한다.

| 이름 | 크기 | 무엇인가 | 쓰는 실험 |
|---|---|---|---|
| **P 정답표** | 100건 (dev 40 / test 60) | 매뉴얼 속 조문 인용(전체 313개에서 층화 추출) | E1 출처 판정 |
| **사람 검수** | 위 100건 전부 | 검수자 1인 독립 판정 + 불일치 26건 최종판정 | E1 세 기준(gold/final/context) |
| **질의 골든셋** | 97문항 (활성 96, 결정 실험 91 = 일반 83 + 범위 밖 8) | 실무형 질문과 기대 결정 | E2 검색(86) · E3 결정(91) |
| **설계 문항** | 9건 (10/7 사전 기록) | 규칙 설계에 참고한 문항 | E3 보조 분석에서 제외 |

## 분모가 달라지는 지점
- **E1**: P 정답표 기준. test 60 / dev 40 / 전체 100. 세 기준(gold·final·context)은 같은 문항 집합·같은 분모를 쓰되 **라벨 정의만** 다르다([e1_label_views.json](../results/e1_label_views.json)).
  - context(답변 가능성) 과제의 '답할 수 있음' 분모: test 39 · 전체 64.
- **E2 검색**: 97문항 중 주소 보유·HOLD 제외 = **86**.
- **E3 결정**: 활성 96 − HOLD 5 = **91**(일반 83 + 범위 밖 8). 설계 문항 9건은 주 결과에 포함하되 보조 분석에서 제외 수치를 따로 보고.

## 중요한 한계 — FAQ 중복
질의 골든셋 **97문항 중 87문항이 매뉴얼 FAQ 질문과 글자까지 같다.** 공개 매뉴얼을 토대로 만든 **초기 진단용 평가셋**이며, **새로운 사용자 질문·다른 기관·다른 규정에 대한 일반화는 아직 검증되지 않았다.** 독립 검수자·신규 표본 재평가는 후속 과제([ROADMAP](ROADMAP.md) P2).

## 라벨 출처
- P 정답표·질의 골든셋의 정답 라벨: **작업보조 LLM 작성 + 교차검토.**
- 사람 검수·최종판정: **설계자 본인 1인.** 정답표를 본 뒤 내린 판정이므로 **독립·외부 검증이 아니다.**
- 세 CSV(gold·review·adjudicated)의 정합성은 `scripts/check_labels.py`가 검사한다(100행·조인·분포·확인 5건·pending 0).
