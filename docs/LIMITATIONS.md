# LIMITATIONS — 알려진 한계·미구현 (v1.0)

이 시스템은 **연구 재현용 소규모 프로토타입**이다. 아래를 분명히 밝힌다.

## 데이터·평가
- **소규모 벤치마크**: 골든 활성 96문항(검색 채점 86), P 정답표 100건. 통계적 결론은 제한적(McNemar는 불일치 건수 중심).
- **LLM 작성 라벨**: 골든·P 정답표는 LLM(작업보조 LLM) 작성 + 교차검토. 사람 독립 검수는 표시된 문항만. "독립 검증된 테스트셋"이 아니다.
- **설계에 쓴 문항**(T: M-077·096·117·266 / A: M-172·198·246·250·063, M-107 추가)은 사례 연구·보조 분석으로만 쓰고 주 정확도 집계에 혼입하지 않는다. 제외 목록은 실행 전에 기록됨(EVAL_SPEC §11).
- **문서 수치 자동 대조**: README·RESULTS·HUMAN_REVIEW의 핵심 수치는 `scripts/sync_numbers.py`가 결과 JSON과 대조하며, 다르면 테스트가 실패한다([NUMBERS](NUMBERS.md)).

## 기능 범위(미구현/프로토타입)
- **시점(T)**: 과거 법령 전 판본을 처리하는 시간 인식 엔진이 **아니다**. 현행 조문의 신설·개정 표시와 **수작업 계보(소수 대표 사례)**로 '낡은 조문 번호 인용'만 탐지한다. 부칙·경과조치 파싱 미구현.
- **적용(A)**: 기관유형·준용 표 기반 '답 불변성' 판정에 한정. 사업유형·규모 등 실제 적용 요건 전면 판단은 아니다.
- **출처(P)**: 규칙 기반 해석기(학습형 아님). 무한정어 인용은 맥락 직전 법령명으로만 확정, 근거 없으면 보류 → 잘못된 보류가 발생한다(E1 참조).
- **검색(E2)**: 임베딩·리랭커 미도입. 자연어 질의 R@5가 낮다.
- **LLM 설명층 없음**: 자연어 답변 문장을 생성하지 않는다. 따라서 '환각률' 지표가 아니라 판정 수준 지표(답변 불가 문항 ANSWER 선택률 등)로 보고한다.

## 운영·보안
- 실제 기밀·개인정보 데이터로 검증하지 않았다. 공개판은 공개 매뉴얼·법령만 포함.
- 운영 배포 시스템이 아니며, 법적 판단을 대체하지 않는다. 사람 검토(게이트의 확인·보류 경로)가 전제다.
- 공개판은 블라인드·비밀·카나리아 '검사 통과'까지만 보장한다("보안 검증"이라 하지 않는다).
