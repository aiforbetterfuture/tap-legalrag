# 합성 예시 (synthetic examples)

공개판에서 해설서 원문(공공누리 제4유형) 없이도 P·T·A 게이트가 어떻게 판정하는지 보여 주기 위한 **직접 작성한 질문**입니다.

- 해설서 문장을 쓰지 않았습니다(원문과 겹침 검사로 확인).
- **평가 수치와 무관합니다.** 시연·진단용입니다.
- 아래 "결정"은 기대값이 아니라 **실제 실행 결과**입니다(config=B4, 코퍼스 판본 CORPUS-20260802).

```bash
PYTHONPATH=src python -m law_rag ask "<질문>"
```

| # | 질문 | 결정 | 판정 경로 | 왜 |
|---|---|---|---|---|
| 1 | 연구기관이 공동연구기관 변경을 요청했습니다. 「국가연구개발혁신법 시행령」 제14조에 따른 협약 변경 절차를 확인해 주세요 | ANSWER | P=확정 → T=현행 → A=무관 | 법령 이름이 인용에 있어 출처 확정, 현행 조문, 기관 유형과 무관 |
| 2 | 작년 매뉴얼에 나온 시행령 제64조 제2항 기준으로 연구기관에 안내해도 될까요? | CONFIRM | P=확정 → T=AMBIGUOUS_HISTORIC | 개정으로 밀린 번호이면서 현행에도 같은 번호 존재 → 현행·종전 후보 2개 제시 |
| 3 | 간접비 비율은 기관마다 다른가요? | CONFIRM | P=n/a → T=n/a → A=BRANCH | 기관 유형별로 답이 갈림 → 유형별로 나눠 제시 |
| 4 | 학생인건비를 연구실 단위로 관리해도 되나요? | CONFIRM | P=n/a → T=n/a → A=ASK | 판단 기준이 되는 상황(대상·단계)을 먼저 되물음 |
| 5 | 제5조에 대해 알려주세요 | CONFIRM | P=unresolved | 어느 법의 제5조인지 단서가 없음 |
| 6 | 「고등교육법」 제2조는 어떻게 되나요? | ABSTAIN | P=external | 이 프로토타입이 다루지 않는 법령 → 보류 |
| 7 | 연구개발비 사용 기준 제45조는 어떤 기관에 적용되나요? | CONFIRM | P=unresolved | **알려진 결함.** 낫표 없이 쓴 고시 이름을 사전이 인식하지 못함. 사람은 바로 알 수 있으므로 "잘못된 보류"에 해당(v1.1 수정 대상) |

7번처럼 **시스템이 틀리는 예시도 일부러 넣었습니다.** 같은 원인이 조문 인용 평가에서 잘못된 보류 10건을 만들었습니다([WORKFLOW 사례 1](../../docs/WORKFLOW.md#사례-1-사전-누락--답할-수-있는데-보류)).

기계가 읽을 수 있는 같은 목록은 [examples.json](examples.json)에 있습니다.
